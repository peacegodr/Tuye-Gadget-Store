  TUYE GADGET STORE ANALYSIS

 Project Overview

This project analyzes the sales performance of Tuye Gadget Store using a provided dataset.
The data was cleaned, transformed, and visualized using Power BI and Power Query to generate actionable insights.

 Data Cleaning & Transformation

Data cleaning was a crucial step due to missing and inconsistent values in the dataset.

* Key Cleaning Steps:
* Removed unwanted and empty columns
* Fixed date inconsistencies
* Converted data types to appropriate formats
* Removed duplicate records
* Created custom columns:
* Time of Day (Morning, Afternoon, Evening, Night)
* Day of the Week
* Month

 Data Modeling

Developed key performance indicators (KPIs) to measure business performance:

* Total Revenue
* Number of Orders
* Number of Products

 Dashboard Analysis

The dashboard provides insights into:

* Revenue by Product
* Revenue by City
* Quantity Sold by Product
* Daily Revenue Trend
* Monthly Revenue Trend

Slicer Used:

Time of Day

 Key Insights
* MacBook Pro and iPhone are the highest-grossing products
* San Francisco is the top-performing city, while Austin has the lowest performance
* Generated a total revenue of $34.49M from 185.95K orders across 19 products
* Sales peak in December
* Revenue is highest on Tuesdays during the afternoon

 Recommendations
* Focus marketing efforts during peak afternoon hours
* Improve sales strategy for low-performing products like AAA Batteries
* Introduce targeted discounts on selected products

 Tools Used
* Power BI
* Power Query
* Microsoft Excel
